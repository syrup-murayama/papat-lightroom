# papat for Lightroom Classic

Lightroom Classic から [papat](https://papat.app/) のギャラリーを作り、クライアントが選んだ写真を Lightroom に取り込むプラグインです。

現在のプラグイン版: **1.2.4**（macOS のみ。Windows は準備中）。インストーラと ZIP は [Releases](https://github.com/syrup-murayama/papat-lightroom/releases) と <https://papat.app/lightroom/> で配っています（同じファイルです）。

- 選んだ写真から、パスコード付きの共有ギャラリーを作る（URL・パスコード・案内文までコピー1回）
- クライアントが「確定」した採用写真を、コレクションに入れて採用フラグ・メモ・タグを反映する
- Lightroom Classic 用（macOS）／ MIT ライセンス

> **English (short):** A Lightroom Classic plug-in for [papat](https://papat.app/) (photo selection, settled in a pat).
> Create a passcode-protected gallery from selected photos, copy the invitation text, and bring the client's adopted
> photos back into a collection (pick flag, memo appended to the caption, tags as keywords — each switchable).
> macOS only for now. MIT licensed. Install: run the signed installer from https://papat.app/lightroom/ (or unzip and add
> `papat.lrplugin` in File → Plug-in Manager), then paste your API key (from https://papat.app/app).
> Your star rating and color labels are never changed. Lightroom's embedded metadata is stripped from the JPEGs before they
> are sent (location, camera serials, develop settings, edit history); only your copyright, creator and contact details
> are written back (switchable), and your star rating is shown in the gallery as "photographer's rating". Support: hello@papat.app. Security issues: see [SECURITY.md](SECURITY.md).

## 必要なもの

- Lightroom Classic（macOS）。Windows 版は準備中です
  - Lightroom SDK 6.0 以降の API だけを使っています。動作確認は、最新の Lightroom Classic（macOS）で行っています
- papat のアカウントと API キー（<https://papat.app/app> で発行）
- インターネット接続

## インストール

最新版のインストーラと ZIP は、**<https://papat.app/lightroom/>** で配布しています（署名・公証済み）。このリポジトリはソースコードです。

### いちばん簡単: インストーラ（.pkg）

1. [papat.app/lightroom](https://papat.app/lightroom/) から `papat-lightroom-<バージョン>.pkg` をダウンロードして**ダブルクリック**します
2. 画面の案内どおりに進めます（管理者パスワードは不要。あなたのユーザー領域だけにインストールします）。途中で「使用許諾」の画面が出ます。送るもの・料金・API キーの扱いと、MIT ライセンスの全文が書かれています
   （使用許諾は版を付けて管理しています。履歴は [docs/license-history.md](docs/license-history.md)）
3. Lightroom Classic を再起動し、**ファイル → プラグインマネージャー → papat** で API キーを貼り付けて **保存**、**接続を確認** を押します

すでに papat が入っている場合は、上書きの前に `~/Library/Application Support/Adobe/Lightroom/papat-lightroom-backups/` へ退避されます。

### ZIP から手動で入れる

1. ZIP（`papat-lightroom-<バージョン>.zip`）をダウンロードして解凍します。`papat.lrplugin` フォルダと `はじめにお読みください.txt` ができます
2. `papat.lrplugin` を**消さない場所**に置きます（おすすめ: 書類 › Lightroom プラグイン）。ダウンロードフォルダのままにしないでください
3. Lightroom Classic で **ファイル → プラグインマネージャー** を開き、左下の **追加** から `papat.lrplugin` を選びます（フォルダごと選びます）
4. **API キー**を貼り付けて **保存**、**接続を確認** を押します

ZIP に入っている同梱の実行ファイル（`papat.lrplugin/bin/papat-fprint`。似た写真をまとめる計算。1.2.0〜）は、
.pkg のものと違って**署名・公証していません**。macOS の検疫で動かないことがありますが、そのときは写真の送信は止まらず、
撮影時刻だけでグループを分けます。似た写真のグループ分けまで使いたい場合は、署名・公証済みの .pkg インストーラーをお使いください。

#### 置き場所に迷ったら（標準の場所にコピー）

追加したあと、プラグインマネージャーの papat の画面にある **標準の場所にコピー…** を押すと、papat が自分自身を
Lightroom の標準の場所（`~/Library/Application Support/Adobe/Lightroom/Modules/`）へコピーします。
Lightroom を再起動すれば、もとの `papat.lrplugin` は削除しても大丈夫です。
ダウンロードフォルダなど標準の場所以外から読み込まれているときは、プラグインの画面に現在の場所と注意が表示され、
最初にメニューを実行したときにも一度だけコピーを勧めます。

#### 標準の場所（Modules フォルダ）について

- Lightroom Classic は起動時に `~/Library/Application Support/Adobe/Lightroom/Modules/` にあるプラグインを自動で読み込みます
  （フォルダがなければ作成して構いません）。「追加」を押す必要はありませんが、プラグインマネージャーで
  「インストール済みで実行中」になっているか確認してください。
- この場所のプラグインは、プラグインマネージャーの **削除** ボタンが使えない（無効化はできる）ことが多いと報告されています
  （Adobe コミュニティの投稿による情報で、公式文書ではありません）。削除するときは、プラグインマネージャーで
  **Finder で表示** → フォルダを削除 → Lightroom を再起動、の順にします。
- システム全体の `/Library/Application Support/Adobe/Lightroom/Modules/` とは別の場所です。通常は上記のユーザー領域を使います。
- 「追加」で別のフォルダから登録した papat と、Modules の papat が一覧に2つ並んだ場合は、
  もとの場所のほう（「読み込み元」の表示で見分けられます）を **削除** してください。

AI エージェント（Claude Code・Codex など）にインストールを任せることもできます。`skill/papat-lightroom-install/` を参照してください。
**API キーは AI に渡さず、必ず自分でプラグインマネージャーに貼り付けてください。**

ZIP・.pkg の改ざん確認が必要な場合は、同じ場所にある `.sha256` と照合できます。

```sh
shasum -a 256 -c papat-lightroom-<バージョン>.zip.sha256
```

## 更新（新しいバージョンが出たとき）

プラグインは自分でファイルを入れ替えません。署名・公証済みのインストーラで更新します。

1. [papat.app/lightroom](https://papat.app/lightroom/) から、新しい `papat-lightroom-<バージョン>.pkg` をダウンロードします
2. `.pkg` を**ダブルクリック**して、画面の案内どおりに進めます（そのまま上書きされます）
   - 古い版は `~/Library/Application Support/Adobe/Lightroom/papat-lightroom-backups/` に自動で退避されます
   - **API キー**と**最近のギャラリー**（URL・パスコード）、設定は、そのまま残ります（Lightroom のパスワード保管領域と環境設定に保存されているため）
3. Lightroom Classic を再起動します

新しいバージョンがあると、「ギャラリーを作る」「セレクトを読み込む」「最近のギャラリー」を使ったときに、**1日1回まで**、控えめにお知らせします（そのまま続けて使えます。「ダウンロードページを開く」か「あとで」）。
サーバーが「この版は使えない」と判断した場合だけ、「更新が必要です」と表示して操作を止めます。
お知らせの確認が通信できないときは、何も表示せず、そのまま使えます。

## 使い方

### ギャラリーを作る

1. ライブラリで写真を選ぶ
2. メニュー **ライブラリ → プラグインエクストラ → papat でギャラリーを作る…**
3. タイトル・保存期間（7日 / 14日）・パスコードを確認して **作成して送信**（ギャラリーの色は、ダッシュボードで変えられます）
4. **すぐに** URL・パスコード・案内文が表示されます。コピーして、クライアントに送れます
5. 写真は**裏で**書き出し・送信されます。ウィンドウを閉じても、Lightroom で現像など他の作業を続けられます（進捗は Lightroom 左上の進捗表示に出ます。✕ で中断できます）。クライアントのギャラリーには、届いた写真から順に並びます

写真は、Lightroom が持っているプレビュー画像（初期設定。**長辺 2048px 前後**・sRGB）か、Lightroom の書き出し（**長辺 2048px・JPEG（画質80）・sRGB**）の JPEG にして送られます（下の「速く送る」）。
**画像に入れるのは、Lightroom に登録した「誰の写真か」だけです。**

| 入る | 入らない |
|---|---|
| 著作権情報（著作権、著作権の状態、使用条件、著作権情報の URL） | 位置情報（GPS、場所の名前） |
| 作成者（と肩書き） | カメラ・レンズのシリアル番号 |
| 作成者の連絡先（住所・電話・メール・Web） | 現像設定、編集履歴、元の RAW のファイル名 |
| | 埋め込みサムネイル、撮影情報（機種・レンズ・露出など） |

Lightroom が書き出したメタデータは、いったんすべて取り除き、上の左の情報だけを、プラグインが画像に入れ直します（Exif と XMP。
Photoshop・Bridge・InDesign や、macOS のプレビューで見られます）。**ファイルが一人歩きしても、誰の写真かが分かります。**
連絡先に自宅の住所を登録している場合などのために、**初めて送るとき（内容が変わったとき）に、入る内容を確認する画面が出ます**。
入れたくないときは「入れずに送る」か、設定（ファイル → プラグインマネージャー → papat）でオフにできます。
RAW 原本は送りません。
書き出しと送信は並行して進み、送信は3本同時に行います。完了すると画面に小さく通知が出ます。
パスコードは papat に暗号化して保存され、papat のダッシュボードでいつでも確認できます（クライアントのブラウザには、ハッシュ値だけが使われます）。

料金の目安（税込）: 1ギャラリー 88円（300枚・7日まで）／14日にすると +88円／300枚を超えるごとに +88円。最初の8ギャラリーは無料です。
実際の金額・無料枠は papat 側の判定が正です（ギャラリーを作る画面の「目安」の横に、サーバーが返す「無料の残り」の数が出ます。取得できないときは出しません）。

#### 案内文（クライアントに送る文面）を自分の言葉にする（1.1.0）

ギャラリーを作ったあとに出る「案内文」は、**自分の文に直して、次回から使えます**。

- **いちばん手早い方法**: ギャラリーを作ったあとの画面で、案内文の欄を書き換えて **「この文面を、次回から使う」** を押します。今回の URL・パスコード・期限の所は「印」になって保存され、次のギャラリーから、その書き方で出ます。
- **改行を入れるとき**: Lightroom の仕組みで、欄で Return を押すと画面の「閉じる」（既定のボタン）が押されます。作ったあとの画面では **「編集中」にチェック**を入れると、そのあいだ「閉じる」が止まり、Return で改行できます（終わったらチェックを外します）。
  それでも改行できないとき、またはプラグインマネージャーの欄では、**「テキストエディタで開く」**で書き換えて保存し、**「編集した内容を反映」**を押します。長い文は、欄の中でスクロールできます。
- **設定で直す**: プラグインマネージャー → papat →「案内文（クライアントに送る文面）」の欄に、もとになる文を書きます。**「もとの文に戻す」**で初期の文に戻ります。
- **差し込みの印**: `{題}`（ギャラリーの題）・`{URL}`・`{パスコード}`・`{期限}`（「10月17日まで」）。題や期限が無いときは、その印だけの行は省かれます。
  `{URL}` や `{パスコード}` を書き忘れても、足りない分は最後に付きます（案内文として使えなくならないように）。印が壊れていたり、知らない印は、そのまま残ります。
- 初期の文は、これまでの案内文と同じです（「写真をお送りします。…ブラウザで開いて、気に入った写真に★を付けて「確定」を押してください。」）。

#### 最近のギャラリー（URL・パスコードの再コピー／続きから送る）

メニュー **ライブラリ → プラグインエクストラ → papat 最近のギャラリー…** で、最近作った10件の URL・パスコード・案内文を、いつでもコピーし直せます。
送信を中断した場合や、一部の写真が送れなかった場合は、同じ画面の **続きから送る** で送り残しだけを送れます（Lightroom を終了していても、同じカタログを開けば続けられます）。
パスコードは、このMacの Keychain（Lightroom のパスワード保管領域）にだけ保存されます。

#### 一覧用の小さな版（1.1.0）

ギャラリーの一覧を軽くするため、写真 1 枚につき**小さな版**（短辺 400px・長辺 800px まで・JPEG）も送ります。
**送った画像（プレビューまたは書き出し）を、macOS の `sips` でまとめて縮めて**作ります。写真の送信の邪魔をしないよう、別の作業で作り、あとから送ります。

- 縮める元は、**送った大きな版そのもの**です。Lightroom の「小さなプレビュー」は使いません（現像を変えたあと、大きな段は新しくなっても、小さな段は古いまま返ることが、実機で分かったため）。一覧と 1 枚表示の見た目が食い違いません。
- 著作権・作成者・連絡先と sRGB のプロファイルは、大きな版と同じく入ります。
- 作れないとき（短辺が 400px 以下の小さな写真・`sips` の失敗）は、その写真だけ小さな版なしで続けます（サーバーが一覧用を作ります）。
- 写真の送信の速さは、1.0.x と同じです。`sips` はまとめて呼ぶため、296 枚で合計 約 8.5 秒（実測。写真の道の外）。小さな版は、最後の数秒でそろいます。

#### 速く送る（Lightroom のプレビューから送る）— 初期設定

**1.1.0 から、初期設定は「速く送る」です。** 書き出しの代わりに、Lightroom が持っているプレビュー画像（長辺 2048px 前後）を送ります。
書き出しよりずっと速く（296 枚の実測: 書き出し 約 8 分、プレビュー 約 1.3 分。サーバーの返事の速さで変わります）、選んでもらうための画像に向いています。
色（画素の値）は書き出しと同じ sRGB で、書き出しと同じく sRGB の ICC プロファイルと、著作権・作成者・連絡先を付けて送ります。
画質・シャープネス・明るさが書き出しと少し違うことがあります（プレビューには出力シャープが掛かりません）。

- **この回だけ書き出す**: ギャラリーを作る画面の **「この回だけ、書き出して送る」** をオンにします（時間がかかります）。
- **いつも書き出す**: プラグインマネージャー → papat →「アタリ送付」で **「速く送る」** をオフにします。
- **現像を変えた直後は、プレビューに反映されていないことがあります**（プラグインからは、プレビューが古いかを見分けられません）。気になるときは「この回だけ、書き出して送る」をオンにするか、
  ライブラリ → プレビュー →「標準サイズのプレビューを作成」をしてから送ってください。
  **色や明るさ、切り抜きを見て判断するクライアントに送る案件では、書き出しをおすすめします。**
- **一括で現像した直後は、少し待ってから送るか、「この回だけ、書き出して送る」を選んでください。**
- 届く画像の大きさと画質は、カタログ設定の「標準プレビューサイズ」と「プレビュー画質」で変わります（標準プレビューサイズ「自動」＋ 4112px の画面なら長辺 2056px、2048 なら 2048px。2560px を超える設定は書き出しに切り替わります）。
  最初に数枚を試し取りして、そのカタログでプレビューが使えなければ、最初から書き出しで送ります。プレビューが取れない写真や、カメラの JPEG のままのプレビュー、大きすぎる・小さすぎるプレビューは、1枚ごとに書き出しに切り替わります（送ったあとの結果に「プレビューから N 枚・書き出しで M 枚」と出ます）。メタデータは、どちらの方法でも取り除きます。
- **1.0.x から更新したとき**: 以前の「速さ優先」の設定は、一度だけ初期設定（オン）に戻ります。オフにしたい場合は、更新後にもう一度オフにしてください。

仕組みと制約の詳細は [docs/fast-mode.md](docs/fast-mode.md) をご覧ください。

### セレクトを読み込む

1. メニュー **ライブラリ → プラグインエクストラ → papat のセレクトを読み込む…**
2. ギャラリーを選ぶ → 一致数と見つからなかった写真を確認 → **コレクションに追加**

採用された写真が、コレクション「**papat 採用 〈ギャラリー名〉 〈作成日〉**」に入り、あわせて次を反映します（設定で個別にオフにできます）。

| 項目 | 内容 | 既定 |
|---|---|---|
| コレクション | 採用写真を「papat 採用 〈ギャラリー名〉 〈作成日〉」に追加 | 常に |
| 採用フラグ | 採用写真に採用フラグを付ける | オン |
| メモ → 説明（Caption） | **追記**。すでにある説明は残し、末尾に新しい行で「`— papat: 〈メモ〉`」を足す。同じギャラリーを読み込み直しても、同じメモは二重に追記されません | オン |
| タグ → キーワード | キーワード「papat」の下にタグを作って付ける（書き出しには含まれません） | オン |
| ★ごとのサブコレクション | コレクションセット「papat 〈ギャラリー名〉 〈作成日〉」の下に「採用」「★3」「★2」… | オフ |
| クライアントの★ → レーティング | **書き込みません**（選択肢にもありません） | — |
| カラーラベル | **触りません**（選択肢にもありません） | — |

クライアントの★は、あなたの現像用レーティングとは別のものです。★の内容は、★ごとのサブコレクションで確認できます。

設定は **ファイル → プラグインマネージャー → papat** の「セレクト受け取り 反映設定」にあります（送る側の設定は、その上の「アタリ送付」です）。

#### 写真の照合

1. このプラグインで作成したギャラリーなら、写真に記録した ID（プラグイン専用の欄）で確実に照合します
2. 記録がなければ、ファイル名の完全一致（大文字小文字は区別しない）
3. それでもなければ、拡張子を除いた名前の完全一致

部分一致や推測はしません。同じ名前の写真が複数ある場合は、反映せずに一覧に出します。

送信先ギャラリーは、プラグイン専用のメタデータ欄（`papat ギャラリー` など。メタデータパネルのプリセット「papat」で確認できます）に記録します。
これはあなたのメタデータ（レーティング・ラベル・キーワード・説明）とは別の欄です。

## プライバシー

- 送信するもの: 縮小した JPEG（著作権・作成者・連絡先だけを入れたもの。設定でオフにできます）、ファイル名、ギャラリーのタイトル、パスコード（本文と SHA-256 値。papat 側で暗号化して保存し、ダッシュボードであなただけが確認できます）、写真ごとのランダムな ID
- 送信しないもの: RAW 原本、位置情報、カメラのシリアル番号、現像設定、カタログ、ファイルのフルパス
- 撮影者の★（Lightroom のレーティング）は、ギャラリーに「撮影者」として表示されます（設定でオフにできます）。カラーラベルは送りません
- API キーは Lightroom のパスワード保管領域（`LrPasswords`）に保存し、ログや画面には出しません
- 通信は HTTPS のみです。ログは `ドキュメント/LrClassicLogs/papat-lightroom.log` に残ります（キーとパスコードは含みません）

| 症状 | 対処 |
|---|---|
| 「API キーが正しくないか、無効」 | ダッシュボードでキーを発行し直し、プラグインマネージャーに貼り付けて保存 |
| 「無料枠を使い切りました」 | ダッシュボード（papat.app/app）でカードを登録 |
| 「公開中のギャラリーが上限の10件に達しています」 | ダッシュボードで不要なギャラリーを終了するか、期限が切れるのを待つ（課金開始前の上限） |
| メニューに出ない | プラグインマネージャーで papat が「有効」か確認し、Lightroom を再起動 |
| コピーできない | 完了画面の案内文欄を選択して Cmd+C |
| 写真が一致しない | ギャラリーを作ったカタログを開いているか、ファイル名が変わっていないか確認 |

それでも解決しない場合は hello@papat.app へ。

## 開発

```sh
scripts/check.sh      # 構文チェック（luac）＋ユニットテスト＋スモークテスト（要 lua / luac）
scripts/package.sh    # dist/ に ZIP と .sha256 を作る
scripts/build-pkg.sh  # .pkg を作る（署名・公証には環境変数が必要。docs/guide-signing.md）
scripts/verify-pkg.sh <pkg>  # .pkg の中身を、インストールせずに検査する
```

- `papat.lrplugin/` — プラグイン本体（Lua 5.1・Lightroom SDK 6.0 以上、外部コマンド・Python・exiftool 不要）
- `tests/run.lua` — Lightroom に依存しない部分のユニットテスト
- `tests/smoke.lua` — Lightroom SDK と papat API をスタブ化して全画面フローを実行するテスト
- `docs/manual-test.md` — Lightroom 実機での確認手順
- `docs/send-pipeline.md` — 書き出しと送信の仕組み／`docs/fast-mode.md` — 速さ優先モードの仕組みと制約
- `docs/guide-signing.md` — .pkg の署名・公証の手順（メンテナー向け）／`docs/installer-notes.md` — インストーラの設計メモ
- `installer/` — .pkg の配布定義・インストール前後のスクリプト・画面文言
- `skill/papat-lightroom-install/` — AI エージェント向けインストール skill

API: papat 連携 API v1（`/api/v1`、Bearer 認証）。
