このプラグインは、村山写真事務所が運営する papat（https://papat.app/）を、Lightroom Classic から使うためのものです。インストールの前に、次の点をご確認ください。

1. 料金

プラグインは無料です。プラグインから作ったギャラリーには、papat の料金がかかります（最初の8ギャラリーは無料）。料金は https://papat.app/ にあります。

2. 規約

papat の利用には、利用規約（https://papat.app/terms/）とプライバシーポリシー（https://papat.app/privacy/）が適用されます。

3. プラグインが送るもの

あなたが選んだ写真を、選定用に縮小した JPEG（長辺 2048px が目安）にして papat に送ります。RAW の原本は送りません。
写真には、Lightroom に登録してある著作権・作成者・連絡先だけが入ります。位置情報、カメラのシリアル番号、現像設定は入りません。
あわせて、ギャラリーの設定（タイトル、パスコード、公開の日数など）と、写真のファイル名、撮影日時、あなたが付けた★を送ります。カメラ名、キーワード、カラーラベルは送りません。

4. Lightroom のカタログ

クライアントのセレクトを読み込むと、採用された写真のコレクションを作ります。初期設定では、採用フラグを付け、クライアントのメモを説明（キャプション）に、タグをキーワードに書き足します（設定でオフにできます）。あなたのレーティングとカラーラベルは書き換えません。
ギャラリーを作るときには、送った写真に papat 用の管理情報を記録します（プラグイン専用の欄です）。

5. API キー

API キーは、あなたのギャラリーを操作できる鍵です。他の人に見せないでください。AI にも渡さないでください。

6. 保証

このプラグインは、現状のまま提供します。動作の保証はありません。大切なカタログは、バックアップを取ってお使いください。
