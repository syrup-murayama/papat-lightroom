Installation complete

  1. Restart Lightroom Classic (quit it first if it is running).
  2. Open File › Plug-in Manager and select papat in the list.
  3. Paste your API key (issued under 連携 in the dashboard at https://papat.app/app) into the API key field and press Save.
  4. Press Check connection (接続を確認). When it says it connected, you are ready.
  5. To use it, choose Library › Plug-in Extras › papat でギャラリーを作る….

Keep your API key private: don't share it, don't paste it into chats or email, and don't give it to an AI.

How to use: https://papat.app/lightroom/
