# 使用許諾の版の履歴

インストーラー（.pkg）の「使用許諾」の画面は、版を付けて管理します。画面の題のすぐ下に「第1版　2026年10月12日」
（英語は "Version 1 — October 12, 2026"）と出ます。版は 1 から始まる整数で、**プラグインの版（1.0.3 など）とは別に数えます**。

## 決まり

- 文を **1字でも**変えたら（`LICENSE` の変更も含む）、版を上げ、日付を改め、この表に行を足します
- 正本は `installer/resources/ja.lproj/license.html` と `en.lproj/license.html`（`LICENSE` の原文と、版の行は、ビルド時に差し込まれます）。
  版と日付は `installer/license-version.txt` の 1 か所で、日本語と英語は必ず同じになります
- 「文が変わったのに版が同じ」「日本語と英語で版が違う」「この表に行が無い」「MIT の原文が `LICENSE` と違う」は、
  `scripts/check.sh`（`scripts/check-license.sh`）と `scripts/verify-pkg.sh` が失敗にします。
  新しいハッシュは `scripts/check-license.sh --hashes` で出ます
- ハッシュは、画面の文（MIT の原文を入れた状態。版・日付の行は除く）の SHA-256 です
- だれがどの版に同意したかは、記録しません（インストーラーからは取れず、サーバーにも送りません）
