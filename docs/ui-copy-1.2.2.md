## この原稿の直し方

- この Markdown のファイルを、直接書き換えてください。文の言い回し・語順・改行の位置など、自由に直して構いません

- 直したら、そのまま置いておいてください。コードへの反映は、こちらで行います
- 迷ったところ・決めかねたところは、見出しのすぐ下に `>` で一行、メモを書いてください（例: `> ここ、もう少し短くできないか`）

## 見出しの〔1.2.0〕〔1.2.2〕について

見出しの横の〔1.2.0〕〔1.2.2〕は、それぞれの版で新しく増えた・変わった画面と文です。そこだけ先に見ていただいても構いません。
〔1.2.2〕は、料金（1 ギャラリー 88 円・88 枚までは 8 円）・分ける大きさ（1,000 枚を超えたら、約 800 枚ずつ）・

## 書き方の約束

- `{枚数}` のような `{…}` は、実行時に差し込まれる値です。`{題}`・`{URL}`・`{パスコード}`・`{期限}` は、案内文のテンプレートの印と同じ名前です
- 画面の部品は、簡単な HTML で表します
  - テキストボックス: `<input value="…">`（複数行は `<textarea>`）
  - チェックボックス: `<label><input type="checkbox" checked> …</label>`（初期でオンなら `checked`）
  - ラジオボタン: `<label><input type="radio" name="…" checked> …</label>`
  - ボタン: `<button>…</button>`（モーダルの下の「実行／キャンセル／もう1つ」のボタンは、「ボタン（モーダルの下）」として並べる）
  - ポップアップ: `<select><option>…</option></select>`
  - 灰色の注意・説明は `<p class="grey">`、赤い注意は `<p class="red">`、太字は `<b>`
- 条件で変わる文は、「条件 → 文」の表にしています。改行は `⏎` で示します（文の中の `\n`）
- 画面の外にある「確認のための OS のダイアログ」（Lightroom の `LrDialogs.confirm` / `message`）は、見出しとして書き、「題」「本文」「ボタン」で示します
- 文言を変えたら、行数を決めている箱があるため、**長さが大きく変わるときは教えてください**（箱の高さは文の長さから計算しています。`lib/text.lua` の `linesFor`）
