# 画面の文言（プラグイン 1.1.0）

校正のための、いま表示している文言の書き出しです。**コードは、この文書を書いた時点の `feature/1.1.0`**（「色（任意）」を作る画面から外した形）。
校正の結果を戻すときは、各見出しの下の「コード」を使います。

## 書き方の約束

- `{枚数}` のような `{…}` は、実行時に差し込まれる値です。`{題}`・`{URL}`・`{パスコード}`・`{期限}` は、案内文のテンプレートの印と同じ名前です
- 画面の部品は、簡単な HTML で表します
  - テキストボックス: `<input value="…">`（複数行は `<textarea>`）
  - チェックボックス: `<label><input type="checkbox" checked> …</label>`（初期でオンなら `checked`）
  - ラジオボタン: `<label><input type="radio" name="…" checked> …</label>`
  - ボタン: `<button>…</button>`（モーダルの下の「実行／キャンセル／もう1つ」のボタンは、「ボタン（モーダルの下）」として並べる）
  - ポップアップ: `<select><option>…</option></select>`
  - 灰色の注意・説明は `<p class="grey">`、赤い注意は `<p class="red">`、太字は `<b>`
- 条件で変わる文は、「条件 → 文」の表にしています。改行は `⏎` で示します（文の中の `\n`）
- 画面の外にある「確認のための OS のダイアログ」（Lightroom の `LrDialogs.confirm` / `message`）は、見出しとして書き、「題」「本文」「ボタン」で示します
- 文言を変えたら、行数を決めている箱があるため、**長さが大きく変わるときは教えてください**（箱の高さは文の長さから計算しています。`lib/text.lua` の `linesFor`）

| パスコードに空白がある | パスコードに空白は使えません。 |
| 上のどちらでもない | （空。「作成して送信」が押せる） |

### 2.2 画像に入れる情報の確認

コード: `lib/ui.lua` の `confirmRights`。Lightroom に登録されている著作権・作成者・連絡先が、**前回と違うとき（初めて、または内容が変わったとき）**だけ出る。何も登録されていなければ出ない

**題:** 画像に入れる情報の確認

**本文:**
```
送る画像には、Lightroom に登録されている次の情報が入ります。⏎
⏎
  {項目名}: {値}   ← 登録されているものだけ（下の項目名の表）
  …
⏎
（写真によって内容が違い、あと {N} 通りの組み合わせがあります。いちばん多いものを表示しています） ← 2通り以上あるときだけ
⏎
位置情報、カメラのシリアル番号、現像設定は入りません。住所や電話番号を登録している場合は、クライアントがダウンロードした画像にも入ります。
設定（ファイル → プラグインマネージャー → papat）でオフにもできます。
```

ボタン: `<button>この内容で送る</button>`　`<button>キャンセル</button>`　`<button>入れずに送る</button>`

項目名（`lib/rights.lua`）: 著作権／著作権の状態（値: 著作権あり／パブリックドメイン）／使用条件／著作権情報の URL／作成者／肩書き／住所／市区町村／都道府県／郵便番号／国／電話／メール／Web

### 4.2 反映する内容の確認

